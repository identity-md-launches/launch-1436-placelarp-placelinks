# Entry-point test coverage

Every entry listed in the assignment has executable local test evidence below. The compiled ABIs contain **149/149** entries: six constructors, 142 functions (counting both `safeTransferFrom` overloads), and one `receive`. This is the complete list called “148” in the brief; no entry was dropped to fit that number. **Entry-point coverage ratio: 1.** This is an entry-point/test inventory, not a claim of 100% line or branch coverage.

The existing tests are retained. Added coverage includes independent name ownership/payment accounting, random crew/friendship sequences, governed-share settlement, late payment rollback, both safe-transfer callback flows, all destination/proxy occupancy subsets, atomic placement retry, and complete constructor rejection matrices using real CREATE. Source, constructor arguments, salts, plan addresses and configuration are unchanged. `Launch.t.sol` now scans the burner's complete constructor arguments, including its names address.

## Reproduction and boundaries

Run `forge build --offline` and `forge test --offline`. No new dependencies are needed. The fixed fuzz seed remains `0x6900` in the existing configuration. Each new invariant campaign uses inline **256 runs × 64 calls**, explicit handler selectors and `fail-on-revert = true`; expected failures assert their precise error instead of being discarded. Deterministic scenario tests prove that handlers reach paid resales, both payment currencies, accepted friendships, invitations, captain succession, name reuse and executed share changes. Existing burner accounting and proposal state-machine invariants remain active.

The pools are the vendored real Uniswap v4 PoolManager with local liquidity. Identity NFTs, payment tokens, Intake and CreateX are local test doubles. Fork tests remain conditional on `MAINNET_RPC_URL`; an offline pass does not establish live Ethereum liquidity or validate the current external deployments. Local placement tests rehearse `PlaceLARP()` followed by `PlaceLinks(placeLARP)` through actual CREATE/CREATE3. No deployment is broadcast.

Known audit behavior is respected: returning ownership may restore an agent; the last-paying name holder may relink for free; share rounding goes to the canonical remainder; fully funded hostile legs can fall back, but insufficient caller gas cannot choose a route. No test requires an acknowledged limitation to disappear.
